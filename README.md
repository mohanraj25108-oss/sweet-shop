# Kanti Sweets — Confectionery & Heritage Mithai SaaS Platform

A modern, production-grade e-commerce & SaaS storefront platform for **Kanti Sweets** (*"Spreading sweetness among people... Since 1957"*), crafted with high-fidelity visual styling, interactive gifting studios, and multi-store management.

---

## 🌟 Key Features

### 1. Storefront Experience (Reference Recreated)
- **Authentic Brand Identity**: Circular floral insignia with heritage typography (*Since 1957*).
- **Delivering From Location Selector**: Real-time store switcher (*Nelamangala Flagship, Indiranagar, Malleshwaram, Koramangala, Whitefield*) with opening hours and distance.
- **Header Actions**: Instant Search Autocomplete, Store Locator, Customer Care, Digital Lookbook (PDF), VIP SweetClub Profile, and Slide-Out Shopping Bag.
- **Royal Purple Navigation Bar (`#741180`)**:
  - Sweets, Namkeens (with open dropdown: *Roasted Namkeens*, *View All*), Snacks, Bakery, Chocolates, Gifting, Candles, Fragrances, Ice Creams, Tea.
- **Artisanal Hero Carousel**:
  - *A Delightful Assortment*: Featuring Dairy Cream Red Velvet Cake, Black Forest Jar Cake, and Vanilla Marble Tea Cake with artisan callouts.
  - *The Heritage Fragrances*: Showcasing Kaanish Armaniya, Dayati, and Miskrdali wooden-capped perfumes.
  - *Royal Pure Ghee Mithai Legacy*: Featuring Mysore Pak and Silver Kaju Katli.
- **Category Discovery**:
  - *"Indulge in the legacy of flavor with Kanti Sweets"* with circular pictorial category chips.

### 2. Interactive SaaS Features
- **Bespoke Sweet Box Studio**:
  - 4-Slot (500g), 6-Slot (750g), 9-Slot (1kg) box capacity.
  - Velvet & Gold keepsake finishes.
  - Slot-by-slot sweet picker with real-time price & weight calculation.
  - Satin golden ribbon & personalized handwritten message.
- **SweetOps Pro™ Merchant SaaS Portal**:
  - Real-time kitchen Kanban pipeline (*Received → In Cooking → QC & Sealing → Out for Delivery*).
  - Fresh batch shelf-life & expiry watchdog (4-day fresh mawa vs. 30-day ghee sweets).
  - 1-click storefront stock status toggle (*In Stock* vs. *Sold Out*).
  - Raw ingredient spot rate index (A2 Gir Cow Ghee, W240 Cashews, Kashmiri Saffron).
- **Corporate & Wedding Hamper Bulk Estimator**:
  - Dynamic volume slab discount calculator (10% to 20% off).
  - Custom gold-foiled corporate logo options.
  - Instant official proforma quote generator.
- **SweetClub VIP Loyalty & Rewards**:
  - SweetCoins wallet balance (1 Coin = ₹1).
  - Order history tracking & re-ordering.
  - Referral program with code sharing.
- **Cart, Checkout & Live Order Stepper**:
  - Free delivery progress indicator.
  - Coupon system (`SWEET10` for 10% off, `KANTI50` for ₹50 off).
  - Simulated payment with canvas confetti celebration.
  - Live 5-stage order tracking stepper with rider contact.

---

## 🛠️ Tech Stack
- **Framework**: React 18 + Vite 6 + TypeScript
- **Styling**: Tailwind CSS with custom royal purple & warm gold palettes
- **Icons**: Lucide React
- **Animations & Effects**: Canvas Confetti, CSS keyframes

---

## 🚀 Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
